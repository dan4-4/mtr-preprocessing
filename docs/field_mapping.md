# Проработка полей: Excel → ResourceItem (Стадия 0)

Источник: `Тестовый.xlsx` (60 позиций из `2_Исходная таблица.xlsx`), лист `Лист1`.

## Маппинг колонок

| # | Колонка Excel | Поле JSON | Тип | Обязательно | Примечание |
|---|---------------|-----------|-----|-------------|------------|
| 1 | № КС | `ks_number` | int | нет | Внутренний номер КС |
| 2 | Шифр сметы | `estimate_code` | string | нет | Напр. `ЛСР-03-05-203ТМ` |
| 3 | 1-Труд / 2-ЭММ / 3-МАТ | `resource_type` | int | нет | В выборке всегда `3` (МАТ) |
| 4 | Column5 | — | — | — | Пустая колонка, не используется |
| 5 | Обоснование | `justification_source` | string | нет | Источник цены + **КСР-код** (regex) |
| 6 | Наименование | `name_raw` | string | **да** | Полное наименование с характеристиками |
| 7 | Ед. изм. | `unit_raw` | string | **да** | Напр. `шт.`, `кг`, `т` |
| 8 | Расход | `consumption` | float | нет | Количество |
| 9 | Базовая цена | `base_price` | float | нет | Цена за ед. |
| 10 | Стоимость | `total_cost` | float | нет | Расход × цена |

## Производные поля (стадия 0)

| Поле JSON | Источник | Алгоритм |
|-----------|----------|----------|
| `item_id` | генерируется | `raw-0001` … `raw-0060` (сквозной ключ) |
| `ksr_code` | колонка «Обоснование» | regex `\d+\.\d+\.\d+\.\d+-\d+` |
| `ksr_name` | `Выгрузка КСР.xlsx` | lookup по `ksr_code` → колонка «Наименование» |

## Статистика на тестовой выборке (60 строк)

| Метрика | Значение |
|---------|----------|
| Строк с КСР-кодом в «Обосновании» | 47 / 60 (78%) |
| Код найден в справочнике КСР | 32 / 47 (68%) |
| Код не найден (устаревший/расширенный) | 15 / 47 (32%) |
| Длина КСР-кода | 11 символов (все) |

## Форматы «Обоснования»

1. **КСР-код в начале** — `08.4.03.03-0009` (код = вся строка или начало).
2. **ТЦ-обоснование без КСР** — `ТЦ_18.1.06.00_50_.../ КА п.70/ ЗАО «...» №897` → `ksr_code = null`.
3. **КСР внутри текста** — regex ищет паттерн в любом месте строки.

## Валидация

- Строка пропускается, если пусты и `name_raw`, и `unit_raw`.
- Ошибка, если `name_raw` или `unit_raw` отсутствуют при непустой строке.
